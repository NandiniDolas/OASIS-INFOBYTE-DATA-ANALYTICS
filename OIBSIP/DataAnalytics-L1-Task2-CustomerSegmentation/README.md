# Customer Segmentation Analysis

## 📌 Project Overview
This project was completed as part of the **Oasis Infobyte Data Analytics Internship (Level 1 — Task 2)**.

The goal is to segment mall customers based on their annual income and spending score using the K-Means clustering algorithm. This helps identify customer groups and understand their spending behavior.

## 🎯 Objectives
- Analyze customer data and identify patterns.
- Explore the relationship between annual income and spending score.
- Apply K-Means clustering to group customers.
- Visualize and interpret customer segments.
- Suggest marketing strategies based on customer behavior.

## 📂 Dataset
**Dataset Name:** `Mall_Customers.csv`

The dataset contains 200 customer records and the following features:
- `CustomerID` — Unique identifier for each customer.
- `Gender` — Customer gender.
- `Age` — Customer age.
- `Annual Income (k$)` — Annual income in thousands of dollars.
- `Spending Score (1-100)` — Spending score assigned to each customer.

## 🛠️ Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🔍 Methodology
1. Loaded and explored the dataset using Pandas.
2. Examined summary statistics and checked the dataset structure.
3. Performed exploratory data analysis using histograms and scatter plots.
4. Selected annual income and spending score for clustering.
5. Standardized the selected features using `StandardScaler`.
6. Used the Elbow Method to help determine the number of clusters.
7. Applied the K-Means algorithm with five clusters.
8. Visualized the clusters and examined customer profiles.
9. Developed marketing recommendations based on customer segmentation.

## 📊 Results
The K-Means algorithm grouped customers into five clusters based on annual income and spending score.

The visualizations help illustrate differences in customer spending behavior and income levels. These segments can support more targeted marketing and customer engagement strategies.

## 💡 Business Recommendations
- Develop loyalty programs for customers who demonstrate high spending.
- Offer relevant promotions to encourage increased engagement.
- Create targeted marketing campaigns for different customer segments.
- Monitor customer behavior to evaluate the effectiveness of marketing strategies.

## 🏁 Conclusion
This project demonstrates how exploratory data analysis and K-Means clustering can be used to understand customer behavior. Customer segmentation can help businesses make more informed marketing decisions and develop strategies tailored to different customer groups.
